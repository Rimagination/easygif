# EasyGIF gallery

画廊案例应保留完整证据链，而不只展示最终 GIF：

```text
source → motion recipe → route plan → frames/contact sheet → final media → manifest/validation
```

每个案例建议包含：

- 原始输入或引用说明
- 主动作、微动作和锁定不变量
- 选择的表示方式与 fallback
- 首帧、中间帧、末帧和循环边界检查
- 最终输出的尺寸、帧数、FPS、透明度和实际字节数
