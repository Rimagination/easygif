# EasyGIF 案例画廊

这些案例用于展示 EasyGIF 对不同应用场景的自适应处理方式。

## 微信表情包：袋熊挠屁股后看镜头

以 3×3 关键帧为参考，保持同一只动物、同一机位和同一背景，只让前爪、眼睛和身体产生低幅度动作。

## 手绘插画：猫猫打哈欠
